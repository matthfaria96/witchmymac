# witchmymac — portfólio de apps

## What This Is
Hub GSD do portfólio do Matheus Faria. Este repo é o site (witchmymac.com) e o "comandador geral" das tarefas que
cruzam vários apps. Cada app vive no seu próprio repositório em `~/Documents/VSCode Temp/`.
