É mesmo de graça? Qual é o truque?

Nenhum truque. Os apps são projetos pessoais que eu uso todo dia e decidi compartilhar. Não há versão paga, assinatura nem anúncios.

É seguro instalar?

O código fonte é público no GitHub e você pode compilar por conta própria. Os apps não pedem permissões além do que precisam para funcionar.

O macOS disse que o app "não pôde ser verificado". E agora?

Isso acontece em apps distribuídos fora da App Store. Clique com o botão direito no app, escolha "Abrir" e confirme. Você só precisa fazer isso uma vez.

Como recebo atualizações?

Cada app avisa quando há uma versão nova. Você também pode acompanhar a página de Releases de cada repositório no GitHub.

Encontrei um bug ou tenho uma ideia.

Abra uma issue no repositório do app no GitHub. Toda sugestão é bem-vinda.
